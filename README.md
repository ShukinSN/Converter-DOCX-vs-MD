# Конвертер DOCX в Markdown Pro

Десктопное приложение на базе PyQt5 для конвертации файлов DOCX в Markdown с современным графическим интерфейсом, функцией предпросмотра, обработкой изображений и интеграцией с BookStack для seamless загрузки в вики.

## Описание

Приложение конвертирует файлы Microsoft Word (DOCX) в Markdown с поддержкой:
- Графического интерфейса с тёмной и светлой темами.
- Предпросмотра Markdown и HTML.
- Автоматической обработки изображений (включая конвертацию EMF в PNG).
- Обработки подписей к таблицам и внедрения стилей.
- Генерации оглавления (TOC) и исправления ссылок.
- Многопоточной пакетной обработки файлов.
- Режима приложений с буквенным обозначением (например, "А", "Б").
- **Интеграция с BookStack**: После конвертации опционально загружайте Markdown-файлы напрямую в BookStack как структурированные страницы в полках и книгах, с автоматической конвертацией в HTML и тегированием.

## Требования

- **Python 3.8+**: Установите с [python.org](https://www.python.org/downloads/).
- **Pandoc 2.14+**: Установите с [pandoc.org](https://pandoc.org/installing.html).
- **ImageMagick**: Требуется для конвертации EMF в PNG. Установите с [imagemagick.org](https://imagemagick.org/script/download.php).
- **Ghostscript**: Необходим для обработки EMF в ImageMagick. Установите с [ghostscript.com](https://ghostscript.com/releases/) или через пакетный менеджер (`brew install ghostscript` на macOS, `apt install ghostscript` на Linux).
- **Экземпляр BookStack** (опционально): Работающий BookStack вики (самостоятельный хостинг или облако). Требуется API-токен (Key:Secret) с правами записи для полок, книг и страниц.
- **Библиотеки Python**: Устанавливаются через `pip install -r requirements.txt` (включает `requests` для API BookStack).

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ShukinSN/Converter-DOCX-vs-MD.git
   cd Converter-DOCX-vs-MD
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. (Опционально) Установите инструменты разработки:
   ```bash
   pip install pyinstaller pytest
   ```

## Быстрый старт

Запустите приложение без сборки исполняемого файла:
```bash
python -m src.main
```

Запустится GUI. Добавьте файлы DOCX/папки, настройте опции (например, TOC, перезапись), выберите папку вывода и начните конвертацию. Для BookStack включите чекбокс и настройте в окне после конвертации.

## Интеграция с BookStack

### Обзор
После успешной конвертации включите "Загружать в BookStack после конвертации" в настройках. Откроется специальное окно для:
- Указания URL BookStack (например, `https://doc.tncpa.ru`).
- Ввода API-токена (формат: `Key:Secret`).
- Выбора или создания полки (коллекция книг).
- Выбора или создания книги (контейнер для страниц).
- Загрузки каждого Markdown-файла как страницы BookStack (автоматическая конвертация в HTML с тегами вроде "converted" и "docx2md").

Это упрощает рабочие процессы для команд документации, использующих BookStack как вики.

### Настройка
1. В панели администратора BookStack: Сгенерируйте API-токен с областями `shelves:write`, `books:write`, `pages:write`.
2. В приложении: После конвертации нажмите кнопку "Открыть BookStack".
3. Введите URL и токен (сохраняются в настройках для будущего использования).
4. Обновите полки, выберите/создайте полку и книгу, затем загрузите.

### Ограничения
- Загрузки создают новые страницы; существующие страницы с тем же именем не перезаписываются (используйте UI BookStack для правок).
- Изображения из Markdown встраиваются как относительные ссылки — убедитесь, что хранилище BookStack их поддерживает (или загружайте отдельно).
- Ошибки (например, неверный токен) логируются в приложении; проверьте консоль для деталей.

## Устранение неполадок

- **Pandoc не найден**: Убедитесь, что Pandoc установлен и добавлен в PATH.
- **Ошибки ImageMagick с EMF**: Проверьте ImageMagick (`magick -version`) и Ghostscript (`gs --version`). На Linux отредактируйте `/etc/ImageMagick-6/policy.xml`, чтобы разрешить EMF (раскомментируйте `<policy domain="coder" rights="read|write" pattern="EMF" />`).
- **Проблемы с PyQt5**: Используйте `pip install PyQt5>=5.15`. На macOS убедитесь в совместимости Qt.
- **Ошибки BookStack**:
  - "Неверный токен": Перегенерируйте токен с правильными областями.
  - "Полка/Книга не найдена": Убедитесь в правах записи; попробуйте создать новые.
  - Проблемы с сетью: Проверьте фаервол/прокси; приложение использует HTTPS.
- **Стили не применяются в предпросмотре**: Файлы CSS должны быть в `src/css/`; пересоберите EXE, если пути неверны.
